# Decision: Describe sorting using application-specific expected EB VA

**Date:** 2026-09-21
**Status:** active

Bruno requested a basic descriptive regression of expected school VA on the
baseline covariates used in the complier exercise, retaining the existing
five primary EB-shrunken observational VA measures rather than switching to
the new RC-VAM estimates.

For each dimension m, construct `E_i[V^m] = sum_j p_ij V_j^m` from the saved
DA probabilities and All-sample EB school values. Regress standardized expected
VA on standardized grade-4 math, grade-4 verbal, income decile, father education,
and mother education, plus a female indicator and assignment-cohort fixed
effects. Continuous variables and each dependent variable are standardized on
one common estimation sample, making coefficients comparable across dimensions.
Female remains binary, so its coefficient is a female-male difference in
expected-VA SD units.

The common sample includes timely 2018-2020 SAE applicants with all covariates,
probability mass one, and complete school-VA coverage across all five dimensions;
the explicit unmatched state receives centered VA zero. This yields 240,007
students. Main comparison statistics are R2 and block partial R2 for achievement
and SES. No municipality fixed effects enter the basic specification because
geographic sorting is part of the descriptive total; a within-municipality
version remains a possible robustness exercise.

Interpretation is ex ante sorting into assignment opportunities generated by
applications, priorities, and the mechanism. It is not a causal effect and does
not separately identify preferences, priorities, geography, or realized
enrollment sorting. Code and outputs: `code/codex/expected_va_sorting/`,
`data/clean/expected_va_sorting/`, and `output/tables/expected_va_sorting/`.
