# Report EB posterior and RSS latent dispersion together in Table 5

Date: 2026-09-23

Table 5 reports both the student-weighted standard deviation of EB posterior
school value added and the cross-cohort RSS estimate of the latent school-effect
standard deviation for each of the seven primary outcomes.

These quantities are shown side by side but labeled separately. The EB SD
summarizes the dispersion of the shrunken school estimates used in the scalar
IV analysis. The RSS SD uses cross-cohort products to estimate latent
across-school dispersion without same-cohort sampling noise. The RSS bootstrap
standard error is reported in brackets. Differences between the two columns
should not be interpreted as disagreement between interchangeable estimators;
EB shrinkage deliberately compresses posterior means, while RSS targets latent
variance.

For readability, Table 5 reports P10, P50, and P90 of the EB posterior
distribution and omits P25 and P75. It includes all seven primary outcomes in
the same order used by the main IV table.
